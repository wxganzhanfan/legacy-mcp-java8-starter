# Code of Conduct

[简体中文](CODE_OF_CONDUCT.md)

This project aims to keep collaboration professional, clear, and grounded in technical facts.

## Expected Behavior

- Discuss issues through technical facts, reproduction steps, code, and documentation.
- Respect contributors with different backgrounds and experience levels.
- When reporting problems, provide actionable context such as versions, configuration, logs, or a minimal reproduction.
- Accept maintainer decisions based on project scope, compatibility, maintenance cost, or security risk.

## Unacceptable Behavior

- Personal attacks, harassment, discriminatory language, or sustained provocation.
- Disclosure of another person's private information, company-internal information, or unauthorized code.
- Repeated submissions unrelated to the project goals.
- Posting real secrets, tokens, cookies, or sensitive business data in issues, discussions, or pull requests.

## Enforcement

Maintainers may edit, hide, or remove content that violates this code, and may temporarily or permanently restrict accounts from participating in the project. Report serious security issues through the process in `SECURITY.md`.
