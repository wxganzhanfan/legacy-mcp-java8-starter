# Changelog

[简体中文](CHANGELOG.md)

## 0.1.0-SNAPSHOT

- Added Java 8 MCP core with `initialize`, `ping`, `tools/list`, and `tools/call`.
- Added explicit interface and annotation tool authoring APIs.
- Added Spring MVC transport and Boot2 auto-configuration through `spring.factories`.
- Added API key agent profiles, tool allowlists, write-tool policy, audit events, and sensitive field masking.
- Added stdio-to-HTTP bridge for stdio-only MCP clients.
- Added Boot2 simple and Spring Security samples.

## 0.1.0-SNAPSHOT

- Initial Java 8 baseline project skeleton.
- Initial MCP core dispatcher and tool registration API.
